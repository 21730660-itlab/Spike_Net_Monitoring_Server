📱 WhatsApp

Set up CallMeBot (2 minutes per person):
  1. On your phone, add +34 644 51 95 23 to your contacts (name it CallMeBot). Check callmebot.com in case the number changed.
  2. Send it this WhatsApp message: I allow callmebot to send me messages
  3. You get a reply with your API key.
  4. In Users, edit the person: WhatsApp number, tick Send me WhatsApp alerts, paste the CallMeBot API key.

CallMeBot is a free third-party service for personal use; messages come from CallMeBot's number, and it may be slow or limited at busy times.

✈️ Telegram recommended

Set up (5 minutes, free, no limits):
  1. In Telegram, open @BotFather, send /newbot, choose a name (e.g. Spike Net Alerts) and a username ending in bot.
  2. Copy the token it gives you into Bot token and click Save settings.
  3. Everyone who wants alerts opens your bot and presses Start. For a team group, add the bot to the group and send any message there.
  4. Click Find chats (below) to see the chat IDs, then put each person's ID on their user (Users page) or the group ID here.
