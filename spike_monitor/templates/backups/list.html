How it works

  • Backups use the device's SSH login and port.
  • MikroTik: a text export (.rsc), used to show what changed, and a .backup file for a full restore.
  • Ubiquiti airOS: the system.cfg file.
  • If nothing changed since the last backup, no new file is stored.
  • To restore: download the file and load it with Winbox (Files → drag the .backup → System → Backup → Restore) or the airOS page.
  • MikroTik exports leave out passwords; the .backup file contains them, so keep downloads safe.
