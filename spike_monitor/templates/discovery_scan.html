Finds devices on the server PC's own network cards with the same broadcast that Winbox's Neighbors tab uses (MikroTik MNDP), plus Ubiquiti discovery. Devices are found even when their IP is in another subnet or they have no IP. Only devices on the same Layer 2 network as the card are seen (not behind a router).

The card's subnet only (for example 192.168.88.0/24) hides the devices of other subnets that the same cable carries. Use This subnet… to see another subnet (several: separate with commas), or All subnets to see everything, like Winbox.

Some devices answer only to their once-a-minute announcement; if one is missing, scan for 30 seconds or more. Nothing found at all? Run scripts\open_firewall.bat as administrator on the server once (it allows UDP 5678 and 10001).
