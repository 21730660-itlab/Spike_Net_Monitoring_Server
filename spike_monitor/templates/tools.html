🖥️ Winbox / SSH helper for this PC

The Winbox and SSH buttons on a device page open the device on your PC, already logged in. Each PC needs this small helper once (no administrator rights, nothing else to install):

  1. ⬇ Download SpikeNetHelper.zip
  2. Right-click the zip → Extract All, open the folder and double-click install.bat.
  3. If it can't find Winbox it asks where winbox.exe is. For SSH it uses PuTTY if installed, otherwise Windows' own ssh.

Security: the button gives the helper a one-time code that expires after 60 seconds; the password is never put in a link. The helper only accepts links from this server ({{ request.base_url }}). Every use is in the audit log.
